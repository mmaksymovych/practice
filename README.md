# Практичні приклади Python

Цей репозиторій містить практичні приклади та навчальні матеріали для вивчення мови програмування Python. Всі приклади організовані за темами та містять детальні коментарі українською мовою.

## 📚 Структура проекту

Проект організований за 7 лабораторними роботами, кожна з яких знаходиться у своїй директорії:

### Лабораторна робота 1: Арифметичні вирази, управляючі конструкції та масиви
**Директорія:** `лабораторна_1/`

Основи Python: типи даних, арифметичні операції, умовні конструкції, цикли та робота з колекціями.

### Лабораторна робота 2: Функції у мові Python
**Директорія:** `лабораторна_2/`

Вивчення функцій: створення, параметри, повернення значень, рекурсія, lambda-функції.

### Лабораторна робота 3: Робота з файлами
**Директорія:** `лабораторна_3/`

Читання та запис файлів, робота з різними форматами, обробка помилок.

### Лабораторна робота 4: Робота з рядками
**Директорія:** `лабораторна_4/`

Операції з текстовими даними: форматування, пошук, заміна, розділення та об'єднання.

### Лабораторна робота 5: Об'єктно-орієнтоване програмування
**Директорія:** `лабораторна_5/`

ООП концепції: класи, об'єкти, наслідування, поліморфізм, інкапсуляція, абстракція та принципи SOLID.

### Лабораторна робота 6: Збір даних з веб-документів
**Директорія:** `лабораторна_6/`

Веб-скрейпінг: парсинг HTML, робота з HTTP-запитами, обробка веб-даних.

### Лабораторна робота 7: Побудова графіків математичних функцій
**Директорія:** `лабораторна_7/`

Візуалізація даних: побудова графіків математичних функцій за допомогою matplotlib та numpy.

## 🚀 Початок роботи

### Вимоги
- Python 3.6 або новіша версія
- Для деяких прикладів можуть знадобитися додаткові бібліотеки (вказано в README кожної теми)

### Встановлення

1. Клонуйте репозиторій:
```bash
git clone git@github.com:mmaksymovych/practice.git
cd practice
```

2. (Опціонально) Створіть віртуальне середовище:
```bash
python -m venv venv
source venv/bin/activate  # На Linux/Mac
# або
venv\Scripts\activate  # На Windows
```

3. Встановіть залежності (якщо потрібно):
```bash
pip install matplotlib numpy requests beautifulsoup4
```
