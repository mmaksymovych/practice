# Тема 1: Арифметичні вирази, управляючі конструкції та масиви у мові Python

## Опис
Цей розділ містить приклади роботи з базовими конструкціями мови Python, включаючи:
- Арифметичні операції та вирази
- Типи даних (числа, рядки, списки, словники, кортежі, множини)
- Управляючі конструкції (if-else, циклами)
- Робота з масивами (списками) та іншими колекціями

## Файли в цьому розділі

### data_types.py
Демонструє роботу з основними типами даних Python:
- Числові типи (int, float)
- Рядки (str)
- Списки (list)
- Кортежі (tuple)
- Словники (dict)
- Множини (set)
- Булеві значення (bool)

### loops_conditions.py
Приклади використання:
- Умовних операторів (if, elif, else)
- Циклів (for, while)
- Операторів break та continue
- Вкладених циклів та умов

## Ключові концепції
- Змінні та присвоєння значень
- Арифметичні операції (+, -, *, /, //, %, **)
- Операції порівняння (==, !=, <, >, <=, >=)
- Логічні операції (and, or, not)
- Індексація та зрізи
- Ітерація по колекціях

## Як використовувати
Запустіть кожен файл окремо для перегляду прикладів:
```bash
python data_types.py
python loops_conditions.py
```
