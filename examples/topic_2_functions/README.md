# Тема 2: Функції у мові Python

## Опис
Цей розділ присвячений роботі з функціями в Python - одному з найважливіших інструментів для створення модульного та повторно використовуваного коду.

## Файли в цьому розділі

### functions_theory.py
Комплексний приклад роботи з функціями, включаючи:
- Оголошення та виклик функцій
- Параметри функцій (позиційні, іменовані)
- Значення за замовчуванням
- Повернення значень (return)
- Область видимості змінних (scope)
- Документування функцій (docstrings)

## Ключові концепції
- **Визначення функції**: використання ключового слова `def`
- **Параметри та аргументи**: передача даних у функції
- **Повернення значень**: оператор `return`
- **Локальні та глобальні змінні**: область видимості
- **Анонімні функції**: lambda-вирази
- **Рекурсія**: функції, що викликають самі себе
- ***args та **kwargs**: змінна кількість аргументів

## Переваги використання функцій
- **Повторне використання коду**: написати один раз, використовувати багато разів
- **Модульність**: розділення програми на логічні блоки
- **Читабельність**: зрозуміліший та організованіший код
- **Тестування**: легше тестувати окремі компоненти
- **Підтримка**: простіше вносити зміни та виправляти помилки

## Як використовувати
```bash
python functions_theory.py
```
