# Тема 4: Робота з рядками у мові Python

## Опис
Цей розділ присвячений роботі з текстовими даними в Python. Рядки є одним з найбільш використовуваних типів даних у програмуванні.

## Файли в цьому розділі

### strings.py
Комплексні приклади роботи з рядками:
- Створення та ініціалізація рядків
- Індексація та зрізи
- Методи рядків
- Форматування рядків
- Пошук та заміна
- Розділення та об'єднання рядків
- Перевірка вмісту рядків

## Ключові концепції

### Основні операції з рядками
- Конкатенація (об'єднання): `+`
- Повторення: `*`
- Індексація: `s[0]`, `s[-1]`
- Зрізи: `s[start:end:step]`

### Корисні методи рядків
- `upper()`, `lower()` - зміна регістру
- `strip()`, `lstrip()`, `rstrip()` - видалення пробілів
- `split()` - розділення рядка
- `join()` - об'єднання списку рядків
- `replace()` - заміна підрядків
- `find()`, `index()` - пошук підрядків
- `startswith()`, `endswith()` - перевірка початку/кінця
- `isdigit()`, `isalpha()`, `isalnum()` - перевірка типу символів

### Форматування рядків
```python
# f-strings (Python 3.6+)
name = "Іван"
print(f"Привіт, {name}!")

# format()
print("Привіт, {}!".format(name))

# % оператор (старий стиль)
print("Привіт, %s!" % name)
```

### Багаторядкові рядки
```python
text = """

рядок в Python
"""
```
