# Тема 5: Об'єктно-орієнтоване програмування у мові Python

## Опис
Цей розділ присвячений об'єктно-орієнтованому програмуванню (ООП) - парадигмі програмування, заснованій на концепції "об'єктів", які можуть містити дані у вигляді полів (часто називаються атрибутами) та код у вигляді процедур (часто називаються методами).

## Парадигми програмування

У програмуванні існує кілька основних парадигм:
- **Функціональна** - організація коду навколо функцій та їх композиції
- **Об'єктно-орієнтована** - організація коду навколо об'єктів та їх взаємодії

## 🧩 Що таке ООП?

Об'єктно-орієнтоване програмування (ООП) - це парадигма програмування, організована навколо об'єктів, а не функцій або логіки. Вона спрямована на структурування програмного забезпечення у повторно використовувані компоненти (об'єкти), сприяючи читабельності, підтримуваності та модульності.

У Python ООП реалізується за допомогою:
- **Класи та об'єкти** - базові будівельні блоки ООП
- **Наслідування** - механізм створення нових класів на основі існуючих
- **Поліморфізм** - можливість об'єктів різних класів реагувати на однакові виклики
- **Інкапсуляція** - приховування внутрішньої реалізації та контроль доступу
- **Абстракція** - виділення суттєвих характеристик об'єкта

## Основні принципи ООП

### 1. Інкапсуляція
Об'єднання даних та методів, що працюють з цими даними, в єдину одиницю (клас) та приховування внутрішньої реалізації.

### 2. Наслідування
Механізм створення нового класу на основі існуючого з можливістю розширення або зміни функціональності.

### 3. Поліморфізм
Можливість об'єктів різних класів реагувати на один і той же виклик методу по-різному.

### 4. Абстракція
Виділення суттєвих характеристик об'єкта та ігнорування несуттєвих.

## Переваги ООП
- **Модульність**: код організований у логічні блоки
- **Повторне використання**: наслідування дозволяє використовувати існуючий код
- **Гнучкість**: легко розширювати та модифікувати функціональність
- **Підтримка**: простіше розуміти та підтримувати структурований код
- **Моделювання**: зручно моделювати реальні об'єкти та процеси
