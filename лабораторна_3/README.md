# Тема 3: Робота з файлами у мові Python

## Опис
Цей розділ демонструє різні способи роботи з файлами в Python, включаючи читання, запис та обробку файлів різних форматів.

## Файли в цьому розділі

### files_rw.py
Приклади роботи з файловою системою:
- Відкриття файлів у різних режимах
- Читання даних з файлів
- Запис даних у файли
- Використання контекстного менеджера (with)
- Робота з текстовими та бінарними файлами
- Обробка помилок при роботі з файлами

## Ключові концепції

### Режими відкриття файлів
- **'r'** - читання (read)
- **'w'** - запис (write), перезаписує файл
- **'a'** - додавання (append), дописує в кінець
- **'r+'** - читання та запис
- **'b'** - бінарний режим (додається до інших режимів)

### Методи роботи з файлами
- `open()` - відкриття файлу
- `read()` - читання всього вмісту
- `readline()` - читання одного рядка
- `readlines()` - читання всіх рядків у список
- `write()` - запис даних
- `close()` - закриття файлу

### Контекстний менеджер
```python
with open('file.txt', 'r') as f:
    content = f.read()
# Файл автоматично закривається
```

## Кращі практики
- Завжди використовуйте `with` для автоматичного закриття файлів
- Обробляйте виключення (FileNotFoundError, PermissionError)
- Вказуйте кодування при роботі з текстовими файлами
- Перевіряйте існування файлів перед роботою з ними

## Як використовувати
```bash
python files_rw.py
```
